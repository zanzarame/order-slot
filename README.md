# 順番スロット

順番スロット（Turn Order Spinner）は、参加者の順番を端末内で決めるWebアプリです。
このリポジトリは、GitHub Pagesで配布する公開版を管理します。

[順番スロットを開く](https://zanzarame.github.io/order-slot/)

## 使い方

1. アプリを開き、参加者を設定します。
2. スロットを開始し、停止して1人ずつ順番を決めます。
3. 全員の順番が決まるまで繰り返します。
